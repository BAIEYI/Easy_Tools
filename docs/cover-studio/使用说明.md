# 封面工坊 2.3 · 公开版

打开 index.html 即可使用，也可从工具导航进入。

1. 填写引导语、核心主题、补充说明与系列信息。
2. 选择背景，或点击“生成全新随机背景”。随机编号随项目保存。
3. 调整字体、主题色与装饰；高级自定义中可开启黑色描边，以 | 分隔需要标红的词语。
4. 点击四图中的卡片，在预览下方调整该比例的字号与位置。垂直 0%/100% 对应可用区域的上下边界。
5. 导出当前 PNG 或全部比例；必要时在浏览器中允许多个文件下载。
6. 保存项目 JSON 可跨电脑继续编辑；自动暂存依赖浏览器本地存储，不能代替备份。

自动换行按宽度与标点适配，强制换行使用回车或 |。超出画布的长标题会自动缩小。节点等图案仅为装饰。

公开版仅包含新生成背景和程序随机背景。旧本地项目的铜棕背景可保持，其余固定背景改用翡翠；随机背景保持种子。字体由系统提供，不同电脑可能呈现不同断行。
